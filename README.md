# ហាងកាហ្វេ «ស្នេហ៍កាហ្វេ (Sne Kafe)» — Landing Page

គេហទំព័រ Landing Page ទំនើបសម្រាប់ហាងកាហ្វេ **«ស្នេហ៍កាហ្វេ (Sne Kafe)»** បង្កើតឡើងដោយ **Nuxt 4**, **Vue 3** (Composition API, `<script setup lang="ts">`), **Tailwind CSS**, **@nuxt/image**, **@nuxt/fonts** (Kantumruy Pro & Inter) និង **Pinia**។

---

## ☕ លក្ខណៈពិសេសនៃគម្រោង (Key Features)

- **Nuxt 4 Architecture**: រចនាសម្ព័ន្ធទំនើប `app/` (pages, components, composables, stores, assets)។
- **ពហុភាសា / Dual Language Support**:
  - ភាសាខ្មែរ (Khmer) & English (EN) ជាមួយប៊ូតុងប្តូរភាសាងាយស្រួលនៅលើ Header។
  - ពុម្ពអក្សរខ្មែរ **Akbalthom (អាក្បាលធំ)** រួមជាមួយ **Inter**។
- **រចនាបថ និងពណ៌ (Design Tokens)**:
  - ពណ៌ផ្ទៃខាងក្រោយ: ពណ៌កាហ្វេដិត (#2B1D16 ដល់ #3A2A21) ជាមួយ Watermark «SNE KAFE»។
  - ចំណងជើង: ពណ៌ខ្សាច់មាសការ៉ាមែល (`#D9A87C`)។
  - អក្សរពិពណ៌នា: ពណ៌កាហ្វេស្រទន់ (`#A88B74`)។
  - ប៊ូតុង និងចំណុចទាក់ទាញ: ពណ៌បៃតងត្បូងកណ្តៀងស្រាល (`#6FA8A3`) ជាមួយអក្សរដិតច្បាស់។
  - កាតទំនិញ: Glassmorphism (ផ្ទៃថ្លាស្រទន់, `backdrop-blur`, `rounded-3xl`)។
- **Интерактивные разделы**:
  1. **AppHeader**: логотип с кофейной чашкой вместо буквы «I», центрированная стеклянная навигация («Главная», «Меню», «О нас», «Отзывы», «Акции») со скролл-спаем, счетчик корзины и кнопка «Сделать заказ».
  2. **HeroSection**: акцентный заголовок, парящие брендовые чашки (коричневая и кремовая) с кофейным всплеском и разлетающимися зернами.
  3. **ProductCards**: карточки с выходящими за верхний край чашками, рейтингом со звездой, описанием, ценой и бирюзовой кнопкой «+» для добавления в корзину.
  4. **AboutSection («BODRIN это»)**: центральная чашка с кнопкой «Заказать» и 4 ключевых преимущества с крупными полупрозрачными цифрами 1–4.
  5. **QuizBanner & QuizModal**: интерактивный тест из 4 вопросов для персонального подбора идеального напитка с возможностью сразу добавить результат в корзину.
  6. **CartDrawer**: выдвижная панель корзины (Pinia store) с управлением количеством, подсчетом суммы и оформлением заказа.
  7. **AppFooter**: ссылки на соцсети, часы работы и копирайт.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 3. Сборка для продакшена
```bash
npm run build
npm run preview
```
